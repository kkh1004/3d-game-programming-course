02 — GOALS

이 수업에서 얻어가는 것

'돌아가는 코드'가 아니라 '고쳐 쓸 수 있는 구조'를 목표로 합니다.

1

게임플레이를 시스템으로 짜기

이동·카메라·전투·AI를 각각 독립된 컴포넌트로 설계해, 기능을 갈아 끼울 수 있는 구조를 익힙니다.

2

3D 공간을 수학으로 다루기

벡터와 회전을 감이 아닌 계산으로 제어합니다. 시야각 판정, 조준, 부드러운 보간까지 직접 구현합니다.

3

예제가 쌓여 포트폴리오로

주차별 실습 결과물을 하나의 프로젝트에 누적합니다. 학기가 끝나면 빌드해서 보여줄 결과물이 남습니다.

03 — CURRICULUM

주차별 강의계획

전반부에서 플레이어를 완성하고, 후반부에서 그 플레이어가 놀 세계를 만듭니다.

PART 1 · 플레이어를 완성한다
01WEEK
오리엔테이션 & 3D 프로젝트 셋업
강의 운영·평가 안내, URP 3D 프로젝트 생성, 씬과 Transform·좌표계 복습, 프로젝트 폴더 구조와 버전관리 습관 잡기
02WEEK
3D 게임 수학 실전
벡터 연산, 내적·외적으로 시야각과 좌우 방향 판별, Quaternion 회전 다루기, Lerp/Slerp를 이용한 부드러운 보간
03WEEK
캐릭터 이동 컨트롤러
CharacterController와 Rigidbody 비교, Input System 입력 처리, 이동·점프·경사면과 계단 처리
04WEEK
3인칭 카메라 시스템
추적 카메라 직접 구현 후 Cinemachine으로 전환, 벽 충돌 회피, 카메라 기준 이동과 조준 모드
05WEEK
애니메이션 연동
Animator 상태 전이, Blend Tree로 이동 블렌딩, 루트 모션 적용, 애니메이션 이벤트로 타이밍 동기화
06WEEK
물리와 충돌 처리
Collider와 Trigger 구분, Raycast·SphereCast 활용, 레이어 마스크 설계, 줍기·문 열기 같은 상호작용 구현
07WEEK
전투 시스템 기초
데미지 처리 구조 설계, 히트박스와 판정 타이밍, 발사체 구현, 오브젝트 풀링으로 성능 확보
08WEEK
중간 실기평가EXAM
1~7주 누적 예제를 통합해, 조작 가능한 플레이어와 전투가 동작하는 플레이어블 씬을 현장에서 구현
PART 2 · 세계를 만든다
09WEEK
적 AI ① 길찾기와 인식
NavMesh 베이킹과 NavMeshAgent 경로 이동, 시야각·거리 기반 플레이어 감지, 장애물 회피와 순찰 경로 설계
10WEEK
적 AI ② 행동 설계
FSM 상태 머신으로 순찰·추적·공격·복귀 흐름 구성, Behaviour Tree 개념 맛보기, 적 유형별 패턴과 난이도 밸런싱
11WEEK
게임 UI / UX
Canvas 구조와 해상도 대응, HP바·크로스헤어·데미지 표시, 인벤토리 UI, 월드 스페이스 UI 활용
12WEEK
게임 데이터 관리
ScriptableObject로 아이템·스탯 데이터 분리, JSON 세이브/로드 구현, 씬 전환과 데이터 유지
13WEEK
사운드 · VFX · 연출
AudioMixer로 사운드 그룹 관리, 파티클 이펙트 제작, 카메라 셰이크와 히트 피드백, 포스트 프로세싱으로 톤 잡기
14WEEK
최적화와 빌드 배포
프리팹 워크플로 정리, 라이트맵 베이킹과 오클루전 컬링, 프로파일러로 병목 찾기, 실행 파일 빌드와 포트폴리오 정리
15WEEK
기말 실기평가EXAM
한 학기 동안 누적한 시스템을 결합한 최종 결과물 구현 및 시연
