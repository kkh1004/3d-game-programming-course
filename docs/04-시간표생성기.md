## 무엇을 하는 앱인가

학과 시간표를 짜는 도구. **과목·강의실을 등록하고, 드래그앤드롭으로 요일·교시에 배치하고,
겹침을 자동 검사하고, 교수별 수업시수를 집계해서 엑셀로 내보낸다.**

가장 활발히 개발 중인 앱이며, 커밋 이력 대부분이 이 파일이다.

## ⚠️ 버전 관리 규칙

기능을 바꾸면 **`APP_VERSION` 을 올리고, 커밋 메시지 끝에 `(vX.Y)` 를 붙인다.**

```
Set the operating weeks per grade (v1.13)
Cap a session at 4 hours and say what to change when it will not fit (v1.12)
```

화면 하단에 버전이 표시되므로, 사용자가 "최신 반영됐나" 확인하는 근거가 된다. 빠뜨리지 말 것.

## 이 앱만의 개념 — 먼저 이해해야 수정할 수 있다

### 1. 반 배치 4칸 구조

요일마다 **보이지 않는 4칸**을 두고 칸 너비를 `2:1:1:2` 로 준다.

```js
var COL_UNITS = [2, 1, 1, 2];
var CLASS_SPANS = {
  '수업': { 'a':[0,0], 'b':[1,2], 'c':[3,3] },   // 셋 다 같은 너비로 보임
  '학적': { 'A':[0,1], 'B':[2,3] }               // 둘 다 같은 너비로 보임
};
```

b반이 두 칸을 차지해도 화면에서는 커 보이지 않게 하려는 장치다.
겹침 판정은 `spanOf()` + `colsOverlap()` 로 한다.

### 2. 시수 → 주차별 배분 (`weekPlan`)

과목의 총 필요 시간은 `hours × 15주` 로 고정이다 (`requiredHours`).
이걸 실제 운영 주차 수로 나누고, **나머지는 앞쪽 주차에 1시간씩 더 얹는다.**

즉 15주짜리 과목을 10주로 압축하면 앞 주차가 더 빡빡해진다. `hoursAtWeek()` / `maxHours()` 가 이 계산을 쓴다.

### 3. 집중이수제 (`courseType === '집중'`)

13~15주처럼 짧게 몰아서 하는 과목은 한 주의 수업시간이 커져 하루에 못 넣는다.
그래서 **"주 N회"로 쪼개 각 회차를 다른 요일에 따로 배치**한다.

- `sessionHours()` — 가장 바쁜 주를 기준으로, **앞 회차부터 `MAX_SESSION_HOURS`(4)까지 꽉 채우고** 남은 걸 뒤로 (예: 주 10시간 · 주 3회 → `4, 4, 2`)
- 다 채우고도 회차가 남으면 그 회차는 만들지 않는다
- `sessionDiagnosis()` / `unfitHours()` — 4시간 상한 안에 안 들어가면 **무엇을 바꿔야 하는지 사용자에게 알려준다** (v1.12에서 추가)
- 배치는 회차별로 따로 존재한다 → `findPlacement(subjectId, session)`

### 4. 총 운영 주차와 "잔여 주차 시간표"

`totalWeeksByGrade` 로 **학년마다** 운영 주차를 따로 정한다 (v1.13).
운영 주차보다 뒤에 시작하는 과목은 `isLeftoverSubject()` → **별도의 "잔여 주차" 보드**에 올라간다.

잔여 주차 보드에서는:
- 같은 학년은 자기 강의실을 다시 써도 된다 (v1.7)
- **다른 학년이 쓰는 강의실은 주차와 무관하게 막힌다** (v1.10)

이 규칙들은 v1.7~v1.10에 걸쳐 여러 번 수정된 곳이다. 건드리기 전에 해당 커밋들을 확인할 것.

## 데이터 구조

**클라이언트 state**
```js
{
  subjects: [],
  rooms: DEFAULT_ROOMS.slice(),
  totalWeeksByGrade: { '1':15, '2':15, '3':15 },
  placements: []
}
```

**서버 state (`Timetable.gs`)** — 구조가 다르다는 점에 주의
```js
{ subjects: [], rooms: [], totalWeeks: 15, boardsByGrade: {'1':[], '2':[], '3':[]} }
```

### 마이그레이션 — 절대 지우지 말 것

`normalizeState()` 가 예전 형식 데이터를 현재 형식으로 올려준다.

- `migrateTotalWeeks()` — 단일 `totalWeeks` → 학년별 `totalWeeksByGrade`
- `migrateBoards()` — 보드 구조 변경 대응
- `migrateWeekRange()` — 주차 범위 형식 변경 대응

사용자의 실제 시간표 데이터가 구글 시트에 살아있다. 이 함수들을 제거하면 **기존 데이터가 통째로 날아간다.**

## 검증 로직

- `checkBase()` — 요일·교시·반 겹침 검사
- `checkRoom()` — 강의실 중복 검사 (학년·주차 규칙 포함)
- `revalidatePlacement()` — 과목을 수정했을 때 기존 배치가 여전히 유효한지 재검사
- `forEachOverlap()` / `dedupe()` — 겹침 순회 보조

## 서버 동기화

- `schedulePush()` → 700ms 디바운스 → `flushPush()` 로 전송 (편집할 때마다 쏘지 않음)
- `pollServer()` 5초 주기, 탭이 백그라운드면 4배 느리게
- `isSharing()` / `setSharing()` — 공유 상태 토글 (v1.6에서 잠금과 함께 토글로 바뀜)
- 잠금: `isUnlocked()` / `requireUnlock()` — 강의실·주차 편집, 내보내기, 학년 초기화가 잠금 대상

## 엑셀 내보내기

`exportWorkbook()` 이 여러 시트를 만든다.
- `subjectSheetRows()` — 과목 목록
- `boardSheet()` + `colOf()` — 시간표 격자
- `loadSheetRows()` / `doExportLoad()` — 교수별 시수
- `autoCols()` — 열 너비 자동 조정

## 백엔드 배포 (`apps-script/Timetable.gs`)

`Code.gs`(index3용)와는 **완전히 별개의 Apps Script 프로젝트**로 배포되어 있다. 데이터 시트도 따로다.

1. script.google.com 새 프로젝트에 붙여넣기
2. 배포 > 새 배포 > 웹 앱 / 실행 사용자: 나 / 액세스: 모든 사용자
3. 발급된 `.../exec` URL을 `index4.html` 의 `API_URL` 에 넣기

저장 위치: 시트 한 줄에 `A1` = 상태 JSON / `B1` = 비밀번호 / `C1` = 리비전 번호

**`.gs` 를 고쳤으면 "배포 관리 > 편집 > 버전: 새 버전"으로 재배포해야 반영된다.** git push는 관계없다.
