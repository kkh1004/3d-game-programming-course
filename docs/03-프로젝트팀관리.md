## 무엇을 하는 앱인가

학생 명단을 엑셀로 올려서 **프로젝트 팀을 짜고, 팀원끼리 상호평가를 받고, 결과를 집계**하는 시스템.
교수와 학생이 **같은 URL을 공유**하며, 데이터는 구글 시트 한 칸에 JSON으로 저장되어 실시간 동기화된다.

## 탭 4개

| 탭 | `data-tab` | 역할 |
|---|---|---|
| 명단 업로드 | `upload` | 엑셀 파일 → 학생 명단 파싱·병합 |
| 팀 배정 | `team` | 드래그앤드롭으로 학생을 팀 슬롯에 배치 |
| 상호평가 | `eval` | 학생이 학번으로 조회해 같은 팀원을 평가 |
| 결과 | `results` | 받은 평가 집계·상세 조회 |

## 핵심 상수

```js
var ROLES = ['기획', '아트', '개발'];      // 팀 내 역할 슬롯
var INDIVIDUAL_GRADES = ['2', '3'];        // 개인 프로젝트로 취급하는 학년
var STORAGE_KEY = 'teamProjectGenState_v1';
var PASSWORD_KEY = 'teamProjectGenPassword_v1';
var DEFAULT_PASSWORD = '1004';
var POLL_INTERVAL_MS = 5000;               // 서버 폴링 주기
var HIDDEN_POLL_FACTOR = 4;                // 탭이 백그라운드면 4배 느리게
```

## 데이터 구조 (서버와 공유하는 state)

```js
{
  roster: [ { grade, section, studentId, name } ],
  teamsByGrade: {},     // 학년별 팀 구성
  assignedMap: {},      // 학생ID → 배정 위치 역인덱스
  evaluations: {},      // 평가 점수
  evalEnabled: false    // 상호평가 개시 여부
}
```

`assignedMap` 은 **파생 데이터**다. `rebuildAssignedMap()` 으로 `teamsByGrade` 에서 다시 만들 수 있다.
팀 구성을 바꾸는 코드를 쓸 때는 이 역인덱스 갱신을 빠뜨리지 말 것.

## 서버 동기화 방식

- 모든 통신은 `callServer()` 하나를 거친다 (Apps Script 웹앱 `.../exec` 로 POST)
- `pollServer()` 가 5초마다 서버 상태를 가져와, JSON 문자열이 달라졌을 때만 `applyServerState()` 로 화면 갱신
- `lastStateJson` 으로 불필요한 리렌더를 막는다
- 로컬 `localStorage` 는 캐시 겸 오프라인 폴백

**여러 명이 동시에 쓰는 앱이다.** 상태를 통째로 덮어쓰는 코드를 넣으면 다른 사람 작업이 날아간다.

## 명단 엑셀 파싱 규칙 (`parseWorkbook`)

까다로우니 고치기 전에 반드시 읽을 것.

- 워크북의 **모든 시트**를 순회한다
- 각 시트 **앞 5행 안에서** `학번` 과 `이름` 이 둘 다 있는 행을 헤더로 인식. 없으면 그 시트는 건너뜀
- 인식하는 열: `No` / `학번` / `이름` / `학적반`
- **시트 이름에서 학년·분반을 추출한다.** 패턴: `^\s*(\d+)\s*-\s*([A-Za-z가-힣0-9])` → 예: `2-A` 면 2학년 A반
- 유효 행 판정: `No` 가 숫자 + `학번` 이 8~10자리 숫자 + `이름` 이 비어있지 않음

즉 **시트 이름 규칙이 곧 학년 정보**다. 이 정규식을 건드리면 명단 업로드가 통째로 깨진다.

## 명단 업로드 모드

- `applyNewRoster()` — 기존 명단을 새 명단으로 교체
- `applyMergedRoster()` — 기존에 덧붙여 병합

교체 모드는 이미 짜놓은 팀 배정에 영향을 준다. 관련 코드 수정 시 `gradeHasAssignments()` 확인 로직을 유지할 것.

## 비밀번호 보호

교수 전용 동작(명단 교체, 학년 초기화, 내보내기, 비밀번호 변경 등)은 `requirePassword()` 를 거친다.
힌트는 **서버에서 만들어 내려준다** (`maskPassword`, 첫 글자 + `*` + 끝 글자) — 어느 PC에서 접속해도 같은 힌트를 보여주기 위함.

## 상호평가

- `canonicalRatingPairs()` — 같은 팀 안의 모든 평가자·피평가자 쌍을 정규 순서로 생성
- `encodeEvaluations()` / `decodeEvaluations()` — 저장 용량을 줄이려 압축 저장
- `computeIncomingRatings()` — 각 학생이 **받은** 평가를 집계
- `evalIsOpen()` 이 `false` 면 학생은 평가 화면에 못 들어간다

## 백엔드 배포 (`apps-script/Code.gs`)

1. https://script.google.com 새 프로젝트에 파일 내용 붙여넣기
2. 배포 > 새 배포 > 웹 앱 / 실행 사용자: 나 / 액세스: 모든 사용자
3. 최초 1회 구글 계정 권한 승인 (교수만, 학생은 불필요)
4. 발급된 `.../exec` URL을 `index3.html` 의 `API_URL` 에 넣기

데이터는 스크립트가 자동 생성한 구글 시트 한 칸(`state` 시트)에 JSON 문자열로 저장된다.

**코드를 고친 뒤에는 "배포 관리 > 편집 > 버전: 새 버전"으로 재배포해야 반영된다.** URL은 유지된다.
git push만으로는 절대 반영되지 않는다.
