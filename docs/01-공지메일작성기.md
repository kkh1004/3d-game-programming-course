## 무엇을 하는 앱인가

교수가 학생·교수진에게 보낼 **공지 메일 초안을 만들고, 그 자리에서 Gmail로 발송**하는 도구.
공지 유형과 대상을 고르면 인사말·본문·맺음말이 자동으로 채워지고, 편집한 뒤 바로 보낸다.

## 화면 구성

**왼쪽 옵션 패널**
- 공지 유형 — `수업관련` / `행사관련` / `학사관련` (3택 1, `data-role="type"`)
- 대상 — `1학년` `2학년` `3학년` `전체` `전체교수` `전임교수` `직접입력`
  - `직접입력` 선택 시에만 자유 입력창과 개별 이메일 추가 UI가 열린다
- 마감일 (선택) — 넣으면 본문에 `※ 마감일은 ...까지입니다.` 줄이 자동 삽입/삭제된다
- 주소록 — 이름·이메일·그룹으로 저장, 그룹은 위 대상 값과 연동

**오른쪽 작성 패널**
- 받는사람 칩, 제목, 본문(contenteditable)
- 복사 / mailto 열기 / 초기화 / 클라이언트 ID 설정 / 도움말
- 구글 로그인 → 보내기

## 핵심 동작

### 본문 자동 생성
`buildSubject()` `buildBodyBase()` 가 유형별 템플릿 상수를 조합한다.

- `TYPE_LABELS` — 제목 앞 대괄호 라벨
- `TYPE_DEFAULT_TITLE` — 유형별 기본 제목
- `TYPE_INTRO2` / `TYPE_DEFAULT_DETAIL` / `TYPE_CLOSING` — 본문 3단 구성
- `TARGET_GREETING` — 대상별 인사말

제목·본문 문구를 바꿔달라는 요청은 **거의 항상 이 상수들을 고치는 일**이다.

### dirty 플래그
사용자가 본문을 직접 손대면 `dirty = true`. 이 상태에서 공지 유형을 바꾸면 `window.confirm` 으로 덮어쓰기를 확인받는다. 대상 변경은 dirty가 아닐 때만 자동 재생성한다.
**본문 재생성 로직을 건드릴 때 이 플래그를 깨뜨리지 말 것.** 작성 중인 내용이 날아간다.

### Gmail 발송
- `initGoogleAuth()` → Google Identity Services (`accounts.google.com/gsi/client`)
- 요청 scope: `gmail.send` + `userinfo`
- `buildRawMessage()` → `utf8ToBase64()` → `toBase64Url()` 로 RFC 2822 메시지를 만들어
  `gmail.googleapis.com/gmail/v1/users/me/messages/send` 에 POST

한글 제목·본문이 깨지는 문제는 대부분 이 base64 인코딩 3단계에서 발생한다.

### 클라이언트 ID
- 기본값 `CLIENT_ID_DEFAULT` 가 코드에 하드코딩되어 있다
- 사용자가 자기 ID로 바꾸면 `localStorage['noticeGoogleClientId_v1']` 에 저장되고 그게 우선한다
- 앱 안에 구글 클라우드 콘솔에서 ID 발급받는 방법이 도움말 모달로 들어있다 (승인된 원본에 `https://kkh1004.github.io` 등록 안내 포함)

## localStorage 키

| 키 | 내용 |
|---|---|
| `noticeGoogleClientId_v1` | 사용자가 직접 넣은 OAuth 클라이언트 ID |
| (주소록 키 `ADDR_KEY`) | 주소록 배열 JSON |

## 수정할 때 주의

- **하드코딩된 클라이언트 ID가 공개 저장소에 노출되어 있다.** OAuth 클라이언트 ID는 원래 공개되는 값이라 치명적이진 않지만, 승인된 원본 설정에 의존한다는 점은 기억할 것.
- 발송은 되돌릴 수 없다. 발송 관련 코드를 고친 뒤에는 반드시 본인 계정으로 먼저 테스트하도록 안내할 것.
- `escapeHtml()` 을 거치지 않고 본문에 사용자 입력을 넣지 말 것.
