## ⚠️ 그라데이션 텍스트 규칙 (v2에서 버그로 고생한 부분)

`background-clip:text` 를 쓸 때 **`background` 단축 속성은 반드시 `background-clip` 보다 먼저** 선언해야 한다.
순서가 뒤바뀌면 clip 설정이 초기화되어 글자가 회색 박스로 보인다. (v1~v2 초반 `.wnum` 버그의 원인)

올바른 순서: `background` → `background-clip` → `color:transparent` → `-webkit-text-fill-color:transparent`

## 사용자가 직접 넣은 커스텀 CSS — 유지할 것

`/*내가 입력한 코드*/` 주석으로 감싸인 블록이 있다. 사용자가 손으로 넣은 것이므로
리팩터링·정리 대상으로 삼지 말고 **주석과 함께 그대로 보존**한다.

```css
/*내가 입력한 코드*/
.sec-num{ margin-top: 80px; }
h2{ background:linear-gradient(105deg,var(--a3) 0%,var(--a2) 20%,var(--a1) 25%);
    -webkit-background-clip:text; background-clip:text; color:transparent; }
/*내가 입력한 코드*/
```

## 스크롤 스파이 동작

- 감지 밴드: `rootMargin: '-45% 0px -50% 0px'`
- 링크 클릭 시 즉시 활성화 후 **900ms 잠금(`lockUntil`)** → 스무스 스크롤 중 하이라이트 깜빡임 방지
- 문서 끝에 닿으면 마지막 섹션(INSTRUCTOR) 강제 활성 → 마지막 링크가 안 켜지던 문제 해결
- 섹션에 `scroll-margin-top:76px` → 앵커 이동 시 제목이 네비에 가리지 않음

이 세 가지는 전부 실제 버그를 고치며 넣은 장치다. 스크롤 코드를 단순화하려 들지 말 것.
