## 🖥️ 새 컴퓨터에서 시작하는 순서

### 1. 저장소 클론

```bash
git clone https://github.com/kkh1004/3d-game-programming-course.git
```

### 2. 커밋 이름·이메일 설정 — **클론해도 따라오지 않는다**

git 설정은 저장소 내용이 아니라 그 PC의 설정이므로 새로 해야 한다.
기존 커밋과 같은 값을 쓴다 (이력이 갈라지지 않도록).

```bash
git config user.name "kkh1004"
git config user.email "beatkkh1004@gmail.com"
```

(`--global` 없이 실행 → 이 저장소에만 적용, 다른 프로젝트에 영향 없음)

### 3. GitHub 인증 — 그 PC에서 **한 번은 사람이 로그인해야 한다**

Claude 는 로그인 창을 띄울 수 없다. 최초 1회만 직접 해주면, 그 뒤로는 Claude 가 push 까지 처리한다.

- 가장 쉬운 방법: **GitHub Desktop** 실행 → 로그인 → `File > Add local repository` → `Push origin`
- 또는 터미널에서 `git push` 실행 후 뜨는 창에서 로그인
- 확인: `cmdkey /list` 결과에 `git:https://github.com` 이 있으면 완료

> ⚠️ GitHub Desktop 의 자격증명(`GitHub - https://api.github.com/...`)과
> git 명령줄의 자격증명(`git:https://github.com`)은 **별개다.**
> GitHub Desktop 만 로그인돼 있으면 명령줄 push 는 여전히 막힌다.

## 🔜 열려 있는 항목

### 2. v1.4 동작 미확인

확인법 — 비번이 있는 학생에게 `제출 초기화` 를 누르고 `제출` 칸을 본다:
`—` 로 바뀌면 정상 / `비번만` 으로 바뀌면 서버가 구버전이다.

## ⚠️ git 에 없는 것 — 절대 코드로 복구되지 않는다

| 데이터 | 사는 곳 | 백업 방법 |
|---|---|---|
| 명단 · 팀 배정 · 평가 점수 | 구글 시트 (Apps Script 가 자동 생성) | 앱의 팀 배정 탭 → `내보내기` (엑셀) |
| 학생 평가용 비밀번호 | 같은 시트 (SHA-256 해시) | 복구 불가 — 잊으면 교수가 초기화 |
| 교수 비밀번호 | 같은 시트 B1 칸 | — |
| Apps Script 프로젝트 자체 | script.google.com | 이 저장소의 `.gs` 파일이 원본 |

**코드를 되돌려도 데이터는 돌아오지 않는다.** 위험한 작업 전에는 엑셀 내보내기를 먼저 할 것.
