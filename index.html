Google Client ID 발급 및 등록 방법

  1. Google Cloud Console(console.cloud.google.com)에서 새 프로젝트를 만듭니다.
  2. "API 및 서비스 > 라이브러리"에서 Gmail API를 검색해 사용 설정합니다. (무료, 결제 계정 불필요)
  3. "API 및 서비스 > OAuth 동의 화면"에서 User Type을 외부로, 게시 상태는 테스트로 둡니다. 범위에 gmail.send를 추가하고, "테스트 사용자"에 실제 사용할 Gmail 주소를 등록합니다.
  4. "API 및 서비스 > 사용자 인증 정보 > 사용자 인증 정보 만들기 > OAuth 클라이언트 ID"를 선택합니다. 애플리케이션 유형은 웹 애플리케이션으로 설정합니다.
  5. "승인된 자바스크립트 원본"에 이 사이트 주소(https://kkh1004.github.io)를 추가하고 저장합니다.
  6. 생성된 클라이언트 ID(...apps.googleusercontent.com로 끝나는 문자열)를 복사합니다.
  7. 이 화면의 "Client ID 변경" 버튼을 눌러 복사한 값을 붙여넣고 저장하면 바로 사용할 수 있습니다.
